# E-commerce Sales Dashboard

## Project Overview
This project analyzes e-commerce sales data using Power BI.

## Tools Used
- Power BI
- DAX
- Power Query

## Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Total Quantity
- Average Order Value

## Dashboard Visualizations
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Payment Method Slicer

## Objective
To analyze sales performance and present key business insights through an interactive dashboard.
